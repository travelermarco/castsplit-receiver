# CastSplit Receiver

Web Receiver Cast personalizzato per [CastSplit](https://github.com/travelermarco/CastSplit): riscrive gli header HTTP (Referer/Cookie/User-Agent) sulle richieste di rete del dispositivo, per far funzionare il cast anche verso siti che proteggono i propri video controllando da dove arriva la richiesta.

Pubblicato via GitHub Pages: `https://travelermarco.github.io/castsplit-receiver/`

Vedi `docs/receiver-cast-personalizzato.md` nel repo principale per come registrarlo sul tuo account Google Cast Developer e collegarlo all'app.
